# CSC430 Proxy Server Project

This project was developed as part of the CSC430 Computer Networks course at the Lebanese American University.

## Project Overview
The project implements a multithreaded caching proxy server using Python. The proxy server accepts client requests, forwards them to target servers, retrieves responses, and relays them back to the client.

## Features
- HTTP proxy forwarding
- HTTPS forwarding support
- Socket programming
- Multithreaded client handling
- Request parsing
- Content caching
- Logging system
- Blacklist/Whitelist filtering

## Technologies Used
- Python
- Socket Programming
- Multithreading
- Networking Protocols
